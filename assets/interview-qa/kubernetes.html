Beginner (48)

001What is Kubernetes, and why do companies use it?

Kubernetes is a container orchestration platform. It automates deployment, scaling, and management of containers across clusters. Companies use it for high availability, auto-scaling, rolling updates, self-healing, and multi-cloud.

002What is a pod?

A pod is the smallest Kubernetes unit wrapping one or more containers, volumes, and networking. Containers in a pod share network namespace (same IP). Pods are ephemeral.

003What is a Kubernetes cluster?

A cluster has control plane (API server, etcd, scheduler, controller manager) and worker nodes (kubelet, container runtime, kube-proxy).

004What is a Deployment?

A Deployment manages pod replicas, handling creation, updates, rollouts, and rollbacks for availability and scaling.

005What is a Service?

A Service provides stable IP and DNS for accessing pods. Types: ClusterIP (internal), NodePort (node port), LoadBalancer (external).

006What is a StatefulSet?

StatefulSet manages stateful pods with stable identities and persistent storage. Use for databases, queues.

007What is a namespace?

Namespaces are virtual clusters within a cluster for isolation and multi-tenancy.

008What is a ConfigMap?

ConfigMap stores non-sensitive configuration as key-value pairs for mounting as files or env vars.

009What is a Secret?

Secret stores sensitive data (passwords, keys, certificates). Base64-encoded by default (encrypt etcd at rest).

010What is an Ingress?

Ingress manages external HTTP/HTTPS access, routing to services by hostname/path.

011What is a PersistentVolume?

PV is cluster-wide storage resource created by admins.

012What is a PersistentVolumeClaim?

PVC is a storage request. Kubernetes binds PVC to PV for persistent data.

013What is a probe?

Liveness probe detects dead pods (restart). Readiness probe detects unready pods (no traffic).

014What is a DaemonSet?

DaemonSet ensures one pod runs on every node. Use for logging, monitoring, networking.

015What is a Job?

Job runs pods to completion. Use for batch tasks.

016What is a CronJob?

CronJob runs jobs on a schedule.

017What are resource requests and limits?

Requests are guaranteed resources. Limits cap usage. Scheduler uses requests for placement.

018What is a label?

Labels are key-value pairs for organizing and selecting resources.

019What is a selector?

Selectors query resources by labels.

020What is an annotation?

Annotations attach non-identifying metadata to resources.

021What is RBAC?

Role-Based Access Control manages who can do what. Objects: Role, ClusterRole, RoleBinding, ClusterRoleBinding.

022What is a role?

Role defines permissions in a namespace.

023What is a ClusterRole?

ClusterRole defines cluster-wide permissions.

024What is an ImagePullSecret?

ImagePullSecret stores private Docker registry credentials.

025What is a NetworkPolicy?

NetworkPolicy restricts pod-to-pod communication (firewall).

026What is a PodDisruptionBudget?

PDB ensures availability during voluntary disruptions (maintenance).

027What is a HorizontalPodAutoscaler?

HPA auto-scales pod replicas based on CPU, memory, or custom metrics.

028What is a VerticalPodAutoscaler?

VPA recommends optimal resource requests for pods.

029What is a priority class?

PriorityClass determines pod scheduling priority.

030What is a taint and toleration?

Taints mark nodes; tolerations allow pods to schedule on tainted nodes.

031What is affinity?

Affinity rules determine where pods can be scheduled relative to other pods or nodes.

032What is anti-affinity?

Anti-affinity spreads pods across nodes for redundancy.

033What is a webhook?

Webhooks are custom logic triggered on API calls (admission, mutation).

034What is a controller?

Controllers continuously ensure desired state matches actual state.

035What is an operator?

Operators extend Kubernetes using custom resources and controllers.

036What is Helm?

Helm packages Kubernetes applications as Charts with templating and versioning.

037What is a ChartRepo?

ChartRepo is a repository of Helm Charts.

038What is a values file?

Values file customizes Chart deployment.

039What is kustomize?

Kustomize customizes Kubernetes manifests without templating.

040What is a custom resource definition?

CRD extends Kubernetes API with custom resource types.

041What is the etcd?

etcd stores all Kubernetes cluster state and configuration.

042What is kubelet?

Kubelet is an agent on each node managing pods and reporting node status.

043What is kube-proxy?

Kube-proxy implements Service networking and load balancing.

044What is CoreDNS?

CoreDNS provides DNS resolution for Kubernetes services.

045What is a network plugin?

Network plugins (CNI) implement pod networking (Flannel, Calico, Weave).

046What is ingress controller?

Ingress controller processes Ingress rules and configures load balancers (nginx, AWS ALB).

047What is a storage class?

StorageClass defines provisioning and characteristics of persistent volumes.

048What is a node selector?

NodeSelector runs pods on nodes with specific labels.

Intermediate (62)

049How do you define resource requests and limits?

Specify in pod spec with memory/CPU requests (guaranteed) and limits (cap). Scheduler uses requests for placement.

050How do you troubleshoot a failing pod?

Use kubectl describe pod, kubectl logs, kubectl exec, kubectl get events.

051How do you perform a rolling update?

Update Deployment spec. Kubernetes gradually replaces pods (respects maxSurge, maxUnavailable).

052How do you rollback a failed deployment?

Use kubectl rollout undo deployment/name or --to-revision=N.

053How do you implement RBAC correctly?

Follow least privilege. Use Roles for namespace, ClusterRoles for cluster-wide. Bind to users/groups/service accounts.

054How do you secure a Kubernetes cluster?

Enable RBAC, Network Policies, Pod Security Policies/Standards, encrypt etcd, audit logging, vulnerability scanning.

055How do you network pods?

Pods communicate via pod IP directly (flat network). Services provide stable DNS and IP.

056How do you use persistent storage?

Create PVC requesting storage, reference in pod volumes. StorageClass auto-provisions PVs.

057How do you handle secrets securely?

Use Secrets, encrypt etcd at rest, RBAC, audit logging. Never commit secrets to Git.

058How do you implement service discovery?

Services register in DNS automatically. Pods query services by name.

059How do you implement multi-tier architecture?

Separate tiers into services with network policies for communication control.

060How do you scale applications?

Use HPA for auto-scaling based on metrics, or manually adjust Deployment replicas.

061How do you implement blue-green deployments?

Run two versions, switch traffic between them using service selector.

062How do you implement canary deployments?

Use traffic splitting tools (Istio, Flagger) to gradually route traffic to new version.

063How do you monitor Kubernetes?

Use Prometheus for metrics, Grafana for visualization, kube-state-metrics for object state.

064How do you use Helm for package management?

Create Charts, use values for customization, install with helm install, upgrade with helm upgrade.

065How do you implement GitOps?

Use tools like ArgoCD or Flux; Git is source of truth, tool syncs automatically.

066How do you handle database migrations?

Use Kubernetes Jobs for migrations, ensure backward compatibility, use DNS for service discovery.

067How do you implement multi-tenancy?

Use namespaces for isolation, RBAC for access control, network policies, resource quotas.

068How do you set up resource quotas?

Define ResourceQuota for namespace to limit CPU, memory, pods, services.

069How do you handle node failures?

Kubernetes auto-reschedules pods on healthy nodes. Use multiple replicas for HA.

070How do you handle cluster autoscaling?

Use Cluster Autoscaler to add nodes when pods can't be scheduled, remove unused nodes.

071How do you implement service mesh?

Use Istio, Linkerd, or AWS App Mesh for service-to-service communication, observability, security.

072How do you use init containers?

Init containers run to completion before app containers start. Use for setup tasks.

073How do you use sidecar containers?

Sidecars run alongside app containers. Use for logging, monitoring, proxies.

074How do you use emptyDir volumes?

EmptyDir creates temporary storage shared by containers in a pod.

075How do you use hostPath volumes?

HostPath mounts node filesystem into pod (use carefully, not portable).

076How do you implement stateful applications?

Use StatefulSet for stable identity/storage, headless Service for direct pod access.

077How do you handle database backups?

Use persistent volumes with backup tools, cross-region replication, or managed services.

078How do you implement cost optimization?

Right-size resource requests, use spot instances, delete unused resources, use cluster autoscaling.

079How do you handle network segmentation?

Use network policies to restrict traffic between pods, namespaces.

080How do you implement service-to-service authentication?

Use mTLS (mutual TLS), service mesh, or API keys.

081How do you handle secrets rotation?

Use external secret management (Vault), operator patterns, or scheduled pod restarts.

082How do you implement distributed tracing?

Use Jaeger, Zipkin, or AWS X-Ray to trace requests across services.

083How do you use container security scanning?

Scan images in registry for vulnerabilities before deployment.

084How do you implement image pulling policies?

Use imagePullPolicy: Always for latest, IfNotPresent to use cached, Never for local only.

085How do you handle image pull errors?

Check ImagePullSecrets, registry authentication, image name, network connectivity.

086How do you implement pod security policies?

Define PSP to enforce security standards (non-root, read-only FS, no privileged).

087How do you use resources efficiently?

Set resource requests/limits, use HPA, implement pod disruption budgets.

088How do you handle node upgrades?

Use kubectl drain to evict pods, upgrade node, uncordon. Pod disruption budgets ensure availability.

089How do you implement logging architecture?

Centralize logs with ELK, Splunk, or cloud services. Use sidecar containers or daemonsets.

090How do you implement health checks?

Use liveness and readiness probes (HTTP, TCP, exec).

091How do you handle graceful shutdown?

Use preStop hooks, SIGTERM handling, drain connections before termination.

092How do you use init containers for setup?

Init containers run to completion before app containers start.

093How do you implement job completion?

Use backoffLimit, activeDeadlineSeconds, parallelism for job control.

094How do you use debug containers?

Add debug containers to pods for interactive debugging.

095How do you implement policy enforcement?

Use pod security policies, network policies, RBAC, and admission webhooks.

096How do you handle load balancing?

Services implement client-side load balancing (round-robin), external load balancers for external traffic.

097How do you use endpoints?

Endpoints track pod IPs for a service, auto-updated as pods come/go.

098How do you implement service federation?

Connect multiple clusters to share services (federation API, ingress).

099How do you handle cross-namespace communication?

Services use DNS service.namespace.svc.cluster.local, networks policies allow/deny.

100How do you implement DNS failover?

Use headless services, SRV records, or DNS-based service discovery tools.

101How do you use external DNS?

ExternalDNS automatically creates DNS records for services/ingress.

102How do you handle SSL/TLS termination?

Use Ingress with TLS cert, or service mesh mTLS termination.

103How do you implement request routing?

Use Ingress for HTTP routing, service mesh for intelligent routing.

104How do you handle request timeouts?

Set connectionTimeout, requestTimeout in service meshes or ingress.

105How do you implement circuit breakers?

Use service mesh (Istio) for auto circuit breaking.

106How do you implement retry logic?

Use service mesh or configure in application code.

107How do you handle rate limiting?

Use service mesh, ingress controller, or application code.

108How do you implement request authentication?

Use ingress auth, service mesh mutual TLS, or API gateway.

109How do you implement request validation?

Use service mesh request validation or API gateway.

110How do you handle request transformation?

Use service mesh or ingress filters.
